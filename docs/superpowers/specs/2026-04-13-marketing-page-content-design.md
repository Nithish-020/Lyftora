**Date:** 2026-04-13
**Status:** Approved
**Reference Template:** [Nova App Template](https://novaapptemplate.framer.website/)

---

## Overview

Marketing landing page for Lyftora — India's AI-powered fitness app. The page follows the structural layout of the Nova Framer template but with completely rewritten content for the fitness domain.

**Target Audiences (segmented messaging):**
- Indian fitness beginners — need convincing an app can guide their fitness journey
- Subscription-fatigued fitness enthusiasts — already using HealthifyMe/Cult.fit, looking for a better experience
- Budget-conscious gym-goers — want affordable AI coaching + accurate Indian nutrition tracking

**Tone:** Motivational & bold + friendly & relatable. Bold but not intimidating.

**Primary CTA:** "Download Now" → Google Play Store
**Pricing Model:** Subscription-based (no pricing section on marketing page — app handles it)

## Design System Alignment

The marketing page should use Lyftora's existing design tokens:

| Token | Value | Usage |
|-------|-------|-------|
| Background | #0A0E1A | Page background |
| Primary / CTA | #00D4AA | Buttons, highlights, headings accent |
| Accent (AI) | #7C6AF7 | AI-specific elements only (Section 2) |
| Surface | #141829 | Cards, elevated elements |
| Surface Elevated | #1C2038 | Input backgrounds, food chips |
| Text Primary | #FFFFFF | Headlines, card titles |
| Text Secondary | #A0A0B0 | Body text, descriptions |
| Text Tertiary | #6B6B7B | Captions, platform notes |
| Border | #2A2E42 | Card borders, dividers |

**Typography:**
- Headlines: DM Serif Display or bold sans-serif (web equivalent)
- Body: Outfit or similar clean sans-serif
- Consistent with app's design language

## Technical Notes

- **Target directory:** `website/lyftora-site/` (already exists as empty directory)
- **Tech:** Vanilla HTML/CSS/JS (no frameworks) as per project instructions
- **Responsive:** Must work on mobile, tablet, and desktop
- **Performance:** Optimize images, lazy-load screenshots, minimal JS
- **Accessibility:** Semantic HTML, proper heading hierarchy (single H1), alt text on all images, sufficient color contrast
- **Analytics:** Add Google Analytics / event tracking on CTA clicks
- **Play Store link:** Placeholder URL until app is published
